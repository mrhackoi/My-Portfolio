01. about

I'm a BCA undergraduate at IGNOU with a Diploma in Cybersecurity from MMIIT (in progress), based in New Delhi. My work sits on the offensive side — vulnerability assessment and penetration testing of web applications and networks — with a defender's habit of writing everything down.

Across seven virtual internships I've tested real targets in controlled scopes: recon and enumeration with Nmap and Gobuster, web assessments with Nikto, and manual testing in Burp Suite for Blind SQLi, Stored XSS, CSRF, LFI and command injection. On the build side, I write Python tooling — a network toolkit with Scapy, a phishing-URL checker — and I've done a full secure coding review of a Flask app where the fixes were verified by automated tests, 6 out of 6 passing.

When I'm not interning, I'm in the lab: Kali, Windows Server 2022, Metasploitable, DVWA and OWASP Juice Shop, or working through rooms on TryHackMe and Hack The Box.

Network Toolkit ↗

Python · Scapy · Tkinter

Network diagnostics and monitoring toolkit with both a CLI and a GUI: packet sniffing, ping, DNS lookup, traceroute and traffic analytics (protocol, packet size, top talkers), with TXT/CSV report export. Verified on Kali Linux — traceroute reached its destination in 9 hops, 20 packets captured on eth0.

Secure Coding Review ↗

Python · Flask · SQLite

Security audit and remediation of a Flask application: parameterized SQL queries, Werkzeug password hashing, input validation, generic auth errors, request size limits, debug mode off. Verified by an automated test suite — 6/6 passing — with a full audit report in the repo.

Phishing URL Checker ↗

Python · CLI

Command-line tool that inspects a URL's text for phishing signals — @ symbols, length over 100 characters, IP-address hosts, 5+ hostname segments, punycode, and HTTP vs HTTPS — and explains every flag it raises.
